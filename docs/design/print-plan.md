# Print plan for PETG on the Bambu A1 (replaced)

**Replaced.** The plan is [`print-plan-abs.md`](print-plan-abs.md): ABS on the Qidi Q2 (the owner, 2026-11-14,
decision record 0008). Use only that plan.

This file was the first plan: PETG on the Bambu A1, for the split of 2026-11-14 (23 pieces of the bare
skin, with stand-ins for the speaker forms, the logo form and the marquee lip). Those pieces, masses,
times and totals are not correct now, so they are removed from this file. The default build now has
30 pieces with their joints ([`print-pieces.md`](print-pieces.md)), the parts of hood band A and the front
socket plate.

The ABS plan says "as the first plan" where it keeps a rule of this plan. It writes each such value
itself. The PETG text (the rules of thumb, the coupons C1 to C11 for PETG, the bond with an adhesive,
the PETG finish and the PETG risks) is in the git history: `git show 17a0502:docs/design/print-plan.md`.
